# 🦫 Капібара онлайн — навчальний проєкт, 6 клас

Самодостатній сайт із теорією, симулятором, інтерактивною вправою, тестом і завантаженням результату у `.md`.

## Запуск

1. Відкрийте `index.html` подвійним клацанням — Інтернет для роботи сайту не потрібний.
2. Для GitHub Pages створіть репозиторій, завантажте **файл `index.html` у корінь репозиторію**.
3. У **Settings → Pages → Build and deployment** оберіть **Deploy from a branch**, гілку `main`, папку `/ (root)` і натисніть Save.
4. Дочекайтеся публікації та відкрийте посилання, яке покаже GitHub Pages.

## Оцінювання

- Симулятор: 5 × 6 = 30 балів.
- Інтерактивна вправа: 5 × 4 = 20 балів.
- Тест: 12 × 4 = 48 балів.
- Бонус: 2 бали за відповіді на всі питання та перевірку всіх трьох розділів.
- Максимум: 100 балів.

Зміст охоплює ГР1 (інформація), ГР2 (цифрові інструменти), ГР3 (комунікація), ГР4 (безпека). Для формального оцінювання за ГР вчитель може уточнити розподіл конкретних завдань.

## Важливо

- Кнопки працюють без сторонніх бібліотек, серверів та API.
- Відповіді зберігаються тільки в пам'яті поточної вкладки; після оновлення сторінки вони скидаються.
- Результати не збираються централізовано. Учень натискає «Завантажити результат .md» і передає файл учителю.
